# Levik VPN для macOS 1.0.0

Первый кандидат macOS-клиента с вертикальным интерфейсом в стиле Windows-версии.
Требуется macOS 13 или новее и действующий аккаунт Levik.

- Levik Account, подписки, серверы, статистика и настройки.
- Xray TUN, глобальная и выборочная маршрутизация, исключения приложений.
- Kill Switch, DNS-защита, DoH и автоматическое переподключение.
- Подключение подтверждается HTTPS-запросом через выбранный VPN-сервер.
- Отдельные установщики для Apple Silicon (`arm64`) и Intel (`x64`).

Откройте DMG, перенесите приложение в «Программы», запустите и войдите через браузер.
При подключении macOS запросит права администратора для настройки туннеля.

Этот кандидат подписан ad-hoc и не нотариализован Apple. При загрузке из интернета
macOS может потребовать подтверждение в настройках конфиденциальности и безопасности.
Обновление такой сборки выполняется вручную новым DMG. Автоматические обновления
требуют выпуска с Developer ID и нотариализацией.

Проверки кода и живого подключения описаны в [отчёте](verification-1.0.0.md).
Сон/смена сети, физический Intel Mac и подписанное OTA пока не проверены.
До выполнения оставшихся сценариев этот кандидат не следует объявлять стабильным
публичным выпуском.
